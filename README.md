# مونتاج (Montaj) — محرر فيديو عربي لويندوز

تطبيق لتحرير الفيديو على سطح المكتب، بواجهة عربية كاملة (من اليمين إلى اليسار)، ويتحدث تلقائيًا.
مبني بـ Electron وReact وFFmpeg، ويستخدم نموذج Whisper لتحويل الكلام إلى نص على جهازك مباشرة.

## الميزات

| المجال | الميزات |
|---|---|
| الوسائط | استيراد فيديو وصور وصوت، صور مصغرة، سحب وإفلات إلى الخط الزمني |
| الخط الزمني | مسار فيديو رئيسي مغناطيسي، ومسارات للنصوص والصوت، وقص الأطراف، والتقسيم (S)، والتكرار، والحذف، وإعادة الترتيب بالسحب، والتكبير، والتراجع والإعادة |
| المقطع | السرعة (من 0.25x إلى 4x)، مستوى الصوت، الكتم، مدة الصور |
| الألوان | 9 فلاتر (حيوي، دافئ، بارد، أبيض وأسود…)، والسطوع والتباين والتشبع |
| الانتقالات | 14 انتقالًا (تلاشي، ذوبان، مسح، انزلاق، دائرة، بكسلة، تكبير…) |
| النصوص | خطوط عربية مدمجة (القاهرة، تجوال، أميري، لاله‌زار)، وأنماط جاهزة، وحد وخلفية، والسحب داخل المعاينة، وظهور تدريجي |
| الترجمة التلقائية | تحويل الكلام إلى نص بالعربية (وبلغات أخرى) دون إنترنت بعد التنزيل الأول للنموذج |
| الصوت | موسيقى أو تعليق صوتي على مسار مستقل مع التحكم في المستوى |
| المقاسات | 16:9 و9:16 و1:1 و4:5 |
| التصدير | MP4 (H.264 + AAC) بدقة من 720p إلى 4K، وبمعدل من 24 إلى 60 إطارًا في الثانية، مع ثلاثة مستويات جودة |
| المشاريع | حفظ وفتح ملفات ‎`.montaj`‎ |
| التحديث | تحديث تلقائي عبر GitHub Releases |

## التشغيل أثناء التطوير

```bash
npm install
npm run dev
```

## بناء ملف التثبيت

```bash
npm run dist
```

ستجد ملف التثبيت داخل مجلد `release/` باسم `Montaj Setup <الإصدار>.exe`.

## التحديث التلقائي

الإصدارات تُنشر في مستودع GitHub:
https://github.com/johnghty1-gif/montaj/releases

يحتاج النشر إلى تسجيل الدخول إلى GitHub مرة واحدة على الجهاز (تم ذلك بالفعل). لإعادته على جهاز آخر:

```bash
scripts\github-login.cmd
```

## نشر إصدار جديد

1. ارفع رقم الإصدار في `package.json`، مثلًا من `0.1.0` إلى `0.2.0`.
2. نفّذ الأمر:
   ```bash
   scripts\release.cmd
   ```

يبني هذا الأمر ملف التثبيت، ويرفعه إلى GitHub، وينشر الإصدار مباشرة.

بعد ذلك يتحقق التطبيق المثبّت من وجود تحديث عند التشغيل وكل 4 ساعات. يُنزَّل التحديث في الخلفية، ثم يظهر شريط فيه زر «إعادة التشغيل والتثبيت». يمكن أيضًا التحقق يدويًا من قائمة «مساعدة ← التحقق من التحديثات».

## بنية المشروع

```
electron/
  main.cjs       النافذة، والقوائم العربية، وبروتوكول media:// لتشغيل الملفات المحلية
  media.cjs      قراءة معلومات الملفات (ffprobe) والصور المصغرة
  export.cjs     بناء أمر FFmpeg للتصدير (المقاطع، والانتقالات، والنصوص، والصوت)
  captions.cjs   الترجمة التلقائية عبر Whisper
  updater.cjs    التحديث التلقائي
src/
  App.jsx        حالة المشروع، والتشغيل، والاختصارات
  components/    المعاينة، والخط الزمني، ولوحة الخصائص، ونوافذ التصدير والترجمة
  lib/           نموذج المشروع، والفلاتر والانتقالات، ورسم النص العربي
```

النصوص تُرسم بمحرك المتصفح، وهو يدعم تشكيل الحروف العربية بشكل صحيح، ثم تُدمج في الفيديو كطبقات PNG. لذلك يطابق شكل النص في الفيديو المصدَّر ما يظهر في المعاينة.

## ملاحظات

- لا يحتاج التطبيق إلى تثبيت FFmpeg على الجهاز، لأنه مدمج فيه.
- نموذج الترجمة يُحفظ في ‎`%APPDATA%\Montaj\models`‎: النموذج السريع حجمه نحو 80 ميغابايت، والنموذج الدقيق نحو 250 ميغابايت.
- لا يحمل التطبيق أيقونة خاصة بعد. ضع ملف `build/icon.ico` بمقاس 256×256 وسيستخدمه البناء تلقائيًا.
